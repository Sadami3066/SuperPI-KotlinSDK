# Security Policy

## Scope

SuperPI-KotlinSDK handles LLM provider credentials, OAuth 2.1 / PKCE flows, MCP tool execution, and local file/shell tool dispatch.

## Reporting a Vulnerability

If you discover a security vulnerability in credential handling, OAuth token storage, path traversal checks, or MCP transport validation:

- **Do not open a public GitHub issue.**
- Report it privately via GitHub Security Advisories on the repository or contact the maintainers directly through GitHub.
- Do not include real API keys or OAuth tokens in any report.
